# 嘉立创 EDA 原理图录入参考 · A0

日期：2026-10-14。交付为五张 3200×2200 PNG，附同名 SVG。按用户要求不生成 KiCad 工程。

1. `01_主控排针.png`：主控板两列候选排母及网络分配。
2. `02_电源与模拟采样.png`：显示5V输入、载板3.3V去耦、主/备用电位器输入。
3. `03_MAX7219电平转换.png`：SN74AHCT125D全部引脚、五信号显示接口。
4. `04_十二路按钮.png`：12套独立上拉、串联电阻与面板接口。
5. `05_换向与辅助输入.png`：换向、EB触点、本地校准及测试点。

相同蓝色网络名在不同页直接互连，GND为公共地。网络名必须逐字一致；跨页录入时使用全局网络标签。图中芯片按完整14脚矩形表示，嘉立创器件库可使用分门符号，但全部电源、使能和未用引脚仍需连接。

本版供电：主控由板上原生USB供电；显示与电平转换器从J90输入独立稳定5V；两者仅共地。J1.21（主控5Vin）明确留空。载板不连接电脑USB VBUS与独立显示5V，不短接主控IN-OUT或USB-OTG焊盘。若后续需要整机单USB供电，须先核对实物电源路径后修改图纸。

J1/J2针序依据YD系列参考，用户板型号/版本和排针尺寸尚未核对：不要据此直接定PCB封装或下单。J5是载板自定义五信号针序，MAX7219模块的实际输入排列要另行核对。ALPS电位器连接使用电阻轨端/滑动端说明，最终端子和封装依厂家尺寸图及实物。

原理图图像和BOM中的R/C均以独立器件计数。未接的GPIO与预留连接器可以按需要省装，但不可更改已使用引脚编号。物理常开按钮、电位器和MAX7219模块属于线束外设；BOM列出载板器件，外设另购。

`BOM.csv`是录入器件清单，`connections.csv`是逐引脚网络对照。生成脚本执行了关键连接断言，但这些不是EDA原生ERC，录入后仍需在嘉立创运行电气检查，复核连接器封装与芯片脚号。当前没有固件、硬件连接或游戏运行验证。
