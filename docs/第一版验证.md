# 第一版实物验证：GPIO5 + SSD1306

> 历史方案：2026-10-21起改为[点阵与GPIO3验证](点阵与GPIO3验证.md)。本文中的OLED接线对应 `s3_oled_legacy`，不适用于当前默认 `s3_uart` 固件。

本版使用现有 ESP32-S3 N16R8、RK097N B10K 三脚电位器和 SSD1306 128×64 I²C OLED。临时接线与 A1 载板参考图不同，烧录时选择 `s3_uart`，通过板上的 CH343 USB 串口通信（本次为 COM4）。

2026-10-19现场记录：完整16MB Flash已备份并生成SHA256；固件烧录与写入校验通过。串口读取约3秒得到136帧有效状态、无解析错误；0x3C地址应答，SSD1306库初始化返回成功。该次ADC始终0，尚未验证转动范围和屏幕实际显示。PC协议12项测试及窗口初始化检查通过。

## 接线

| 器件端子 | 连接 |
| --- | --- |
| 电位器滑动端 | GPIO5；推荐串联1kΩ，GPIO5侧接100nF到GND |
| 电位器两侧端 | 3V3 / GND；推荐3V3经4.7kΩ后接电位器上端 |
| OLED VCC / GND | 3V3 / GND |
| OLED SCL / SDA | GPIO10 / GPIO11 |
| 原GPIO4 / GPIO6接线 | 拆除，固件保持输入状态 |

各器件共地。电位器端子顺序以万用表测量为准：两端间约10kΩ且转动不变，滑动端到两端的阻值随转动变化。本版不启用按钮或MAX7219，避免占用GPIO10/11。

直接使用3V3分压时，先观察靠近高端是否出现一段连续4095；若多个机械卡位都落在饱和段，应增加上述4.7kΩ限幅电阻后重新校准。屏幕显示 `TOP SAT` 仅作为排查提示。交换电位器两侧端可反转读数，校准支持两个方向。

## 编译与烧录

在仓库根目录运行：

```powershell
python -m platformio run -d firmware -e s3_uart
python -m platformio run -d firmware -e s3_uart -t upload --upload-port COM4
```

`s3_native_usb` 是原生USB接口的备用配置；当前CH343连接使用 `s3_uart`。固件不依赖PSRAM。刷写前的完整Flash备份保存在本机 `hardware_backups/`，不提交仓库。

## 采样和校准

1. 双击 `test_tools/启动第一版验证.cmd`，选择当前串口并连接。默认仅监看，不创建虚拟手柄。
2. 检查ADC读数随手柄平滑变化；OLED应显示ADC与 `Need 15-point cal`。检测地址为0x3C或0x3D；收到地址ACK不等于已确认屏幕型号，需实看显示。
3. 点击“开始校准”，将手柄停稳在EB，点击“采集当前卡位”。窗口自动选择下一档。
4. 按 `EB、B8、B7、B6、B5、B4、B3、B2、B1、N、P1、P2、P3、P4、P5` 逐个采集实际机械卡位。N的位置由实测决定，不假定在行程正中。
5. 点击“校验并保存”。要求15点齐全、读数严格单调、相邻间隔至少25、总跨度至少500。出现错误先查看日志，不会覆盖原有有效校准。
6. 保存成功后逐档拨动，检查OLED和窗口显示；断电重启后再检查校准是否保留。校准保存于NVS，重新刷写若未擦除该区域通常会保留。

采样使用8次均值和EMA滤波，档位边界采用相邻中心值中点并加入迟滞。OLED更新使用阻塞I²C传输，因此串口报告并非严格固定50Hz。屏幕缺失不阻止ADC和串口运行。

## 游戏链路

1. 校准并确认全部档位后，点击“创建虚拟手柄”，初始输出N，然后启动游戏。
2. 物理手柄置N，点击“手柄置N后启用输出”。先在游戏静止时逐档确认HUD。
3. 串口超过500ms无有效数据、设备重启、开始校准或断开连接时，桥接程序发送N并停用输出；恢复后必须再次手动启用。窗口卡住时无法保证实时发送，此逻辑不是硬件故障保护。
4. 结束前停止输出并置N，再关闭窗口。

全部15档的游戏识别仍需逐项验证，尤其EB。此前仅P1/P3/B5由用户在E233 0番台确认。本版还需实测ADC跨度、卡位抖动、OLED显示和断线行为。

## 软件检查

```powershell
python -m unittest discover -s test_tools -p test_serial_protocol.py -v
```

协议包括版本、启动标识、序号、ADC和校准状态；PC丢弃格式错误或重复/倒序状态。接收线程记录到达时刻，窗口积压的旧数据不会被当作新鲜输入重新启用。
