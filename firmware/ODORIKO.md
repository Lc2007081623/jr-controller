# Hidari 2 与 Odoriko

Hidari 2 固件 `c3_hidari_2` 从 1.2.0 起支持 Odoriko 模型模式。模式在控制器上选择，可脱离上位机运行。

| U9 四针 | Odoriko |
| --- | --- |
| 1 · MODULE_5V | 5 V OUT，SW1 选择模块供电时给 Hidari 2 供电 |
| 2 · GND | GND |
| 3 · MODULE_A / GPIO3 | DRV8871 IN2 |
| 4 · MODULE_B / GPIO4 | DRV8871 IN1 |

12 V 供电和轨道线直接接 Odoriko。断电换插 U9。确认主手柄已完成校准。

菜单按键按上位机校准后保存在控制器上的 A、B、X、Y 映射识别。

1. 上电默认 `PC` 模式。主手柄、换向器均置 `N`，同时长按 A＋Y 约 1 秒，进入点阵菜单。任一手柄未回空挡时按住 A＋Y，点阵闪烁 `N`，两柄回空挡后开始计时。
2. 松开两键。用 A 或 B 选 `PC` 或 `Od`，用 X 确认，Y 返回。菜单中轨道输出关闭。点阵显示 `Hn` 时主手柄须回 `N`，显示 `rn` 时换向器须回 `N`。
3. 确认 `Od` 并松开按键后，保持主手柄在 `N`，拨换向器到 `F` 或 `R`。P 档逐步增加 PWM，主手柄在 `N` 时按滑行掉速参数逐步降低 PWM，B 档按制动参数降低 PWM。
4. 换向器回 `N` 或离开当前方向时立即撤掉驱动。两柄回 `N` 后即可拨新方向。小车是否已经停稳靠现场确认。
5. 进入 EB 立即切断驱动。主手柄回 `N` 后解除 EB，保留未改变的换向方向。短按 Y 或发生输入故障会锁定驱动，解除故障、两柄回 `N` 后按 X 确认。驱动关闭时 DRV8871 输出高阻，小车会滑行。

## 上位机调参

在上位机 1.1.4 的「软件设置 → N 比例模块」读取或保存 P 档加速、N 档滑行掉速和 B 档减速。调参需要 Hidari 2 固件 1.2.2 或更新版本。三项默认值为 30、40、50，范围为 1–255，单位为每秒 PWM 计数。P、B 档的实际变化速率再乘档位号。参数保存在控制器内，脱离电脑后仍生效。

串口使用 `ODGET` 读取，使用 `ODSET 30 40 50` 设置并保存，顺序为加速、滑行掉速、制动减速。成功后设备返回 `odoriko_config`。在模型模式保存前，将两柄置 `N`。

烧录时用实际识别到的串口。在仓库根目录运行：

```powershell
pio run -d firmware -e c3_hidari_2 -t upload --upload-port COM15
```
