# Hidari 2 与 Odoriko

Hidari 2 固件 `c3_hidari_2` 从 1.2.0 起支持 Odoriko 模型模式。模式在控制器上选择，可脱离上位机运行。

| U9 四针 | Odoriko |
| --- | --- |
| 1 · MODULE_5V | 5 V OUT，SW1 选择模块供电时给 Hidari 2 供电 |
| 2 · GND | GND |
| 3 · MODULE_A / GPIO3 | DRV8871 IN2 |
| 4 · MODULE_B / GPIO4 | DRV8871 IN1 |

12 V 供电和轨道线直接接 Odoriko。断电换插 U9。确认主手柄已完成校准。

菜单按键按上位机校准后保存在控制器上的 A、B、X、Y 映射识别。

1. 上电默认 `PC` 模式。主手柄、换向器均置 `N`，同时长按 A＋Y 约 1 秒，进入点阵菜单。任一手柄未回空挡时按住 A＋Y，点阵闪烁 `N`，两柄回空挡后开始计时。
2. 松开两键。用 A 或 B 选 `PC` 或 `Od`，用 X 确认，Y 返回。菜单中轨道输出关闭。点阵显示 `Hn` 时主手柄须回 `N`，显示 `rn` 时换向器须回 `N`。
3. 固件 1.2.6 起，拨换向器到 `F` 或 `R` 即可按当前主手柄档位运行。P 档加速，主手柄在 `N` 时滑行降速，B 档制动。降至最低输出电压后维持该电压。
4. 换向器回 `N` 时输出归零。确认小车停稳后再选另一方向，主手柄无需回 `N`。新方向从设定的最低电压起步，再按当前档位调整输出。
5. EB 默认输出归零，主手柄回 `N` 后解除。固件 1.2.7 起，可分别设置 EB 输出归零或降至最低电压，以及是否必须回 `N` 才能解除。换向器在 `N` 或输入故障时始终输出零。短按 Y 或发生输入故障会锁定驱动，故障解除且换向器稳定后可按 X 确认恢复。驱动关闭时 DRV8871 输出高阻，小车会滑行。

## 上位机调参

在上位机的「设定 → 模型驾驶」读取或保存 P 档加速、N 档滑行掉速、B 档减速和最低输出电压。速率的默认值为 30、40、50，范围为 1–255，单位为每秒 PWM 计数。P、B 档的实际变化速率再乘档位号。最低输出电压默认为 0 V。参数保存在控制器内，脱离电脑后仍生效。

串口使用 `ODGET` 读取，使用 `ODSET 30 40 50` 设置并保存，顺序为加速、滑行掉速、制动减速。可加第四项最低电压，单位为 0.01 V，例如 `ODSET 30 40 50 200` 为 2 V。成功后设备返回 `odoriko_config`。固件 1.2.6 起，无论当前模式，保存前都须将两柄置 `N`。

固件 1.2.7 增加第五项 `eb_flags`。默认值为 0，第 0 位表示 EB 保留最低电压，第 1 位表示离开 EB 即可解除。旧格式的保存命令保留已有 EB 设置。

烧录时用实际识别到的串口。在仓库根目录运行：

```powershell
pio run -d firmware -e c3_hidari_2 -t upload --upload-port COM15
```
