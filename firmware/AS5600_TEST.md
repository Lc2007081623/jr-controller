# AS5600角度验证：ESP32-S3，SDA7 / SCL15

2026-10-24现场识别：COM4为原ESP32-S3 N16R8，不是计划中的C3。本测试仅适用当前S3，编译时会阻止误用到C3。

| AS5600模块 | 当前S3开发板 |
| --- | --- |
| VCC | 3V3（用户提供的模块明确标注3.3V） |
| GND | GND |
| SDA | GPIO7 |
| SCL | GPIO15 |
| DIR | GND |
| OUT / GPO | 外部留空 |

在原始角度寄存器0x0C/0x0D读取12位角度，并检查0x0B磁场状态。采用100kHz I2C，串口115200，每100ms输出一行JSON。`valid=true`要求检测到磁铁且磁场不过弱/过强。`raw`是0～4095，`degrees`为`raw*360/4096`；无效时这些值不应被当作可靠角度。0°/360°处原始数值自然跳变，本测试不做档位映射。

上电会扫描I2C地址1～126，并报告总线初始电平。2026-10-24最初按SDA15/SCL7测试时扫描为空；随后用户确认实际接线为SDA7/SCL15，程序已修正。后续验证以修正后的接线为准。

修正后实测：地址0x36应答，27帧全部通信成功、磁场状态有效，未报告磁场过弱/过强；当时RAW为3638～3639，约319.75°。这是一段静止读数记录，转动范围、双向重复性和档位映射仍待验证。

可视窗口：双击 `test_tools/查看AS5600角度.cmd`，自动连接COM4，显示角度、RAW和磁铁状态。关闭后释放串口，勿与其他串口程序同时占用COM4。无效磁场或超时会隐藏角度，不把旧值当作当前有效角度。

```powershell
python -m platformio run -d firmware -e s3_as5600_test -t upload --upload-port COM4
python -m platformio device monitor -p COM4 -b 115200
```

这是独立传感器验证程序，不发送第一版手柄协议，也不驱动点阵或按钮。不会写AS5600配置/OTP或电位器校准NVS。原来的`s3_uart`仍是第一版默认环境；恢复时先核对原有硬件接线，再上传该环境。

寄存器与磁场位定义依据：[ams OSRAM AS5600数据手册](https://look.ams-osram.com/m/7059eac7531a86fd/original/AS5600-DS000365.pdf)。
