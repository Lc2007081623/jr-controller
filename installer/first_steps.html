JR CONTROLLER / 1.1.4 / Windows 10、11 64 位

接上控制器，开始驾驶

适用于配套、已烧录固件的 ESP32-C3 控制器。安装包已包含运行环境和手柄驱动，不需要 Python，不需要额外下载依赖。

1. 安装到电脑

  1. 退出旧版 JR 控制器和正在运行的游戏。
  2. 双击 JRControllerSetup.exe。Windows 询问是否允许更改设备时，需要管理员同意。若系统拦截安装，请联系提供安装包的人核实文件，不要关闭系统防护。
  3. 点击“一键安装”。等待程序安装驱动、复制程序并检查四个游戏输出模式。
  4. 若提示需要重启，先保存电脑上其他工作并重启，再从桌面打开 JR Controller。未要求重启时，可直接从桌面打开。
“登录后自动运行”表示下次登录时最小化运行；安装完成当次请从桌面打开程序。驱动检查不需要连接实体控制器，也不代表游戏已经识别。

2. 用 USB 连接硬件

  1. 使用能传输数据的 USB 线，连接控制器配套的原生 USB 接口。
  2. 打开 JR Controller。正常情况下会自动连接，不需要选择 COM 口。
  3. 拨动手柄、换向开关并按四个按钮，查看软件中的档位、F/N/R 和按钮亮起状态。
选择 JR EAST（Xbox）模式后，点击「启动 JR EAST」。首次选择 Steam 或游戏 EXE，之后软件会等控制器输出就绪再启动游戏。要更换入口，点击「启动设置」。
在「软件设置 → 按键映射」可为四个实体键选择键盘键、Xbox 360 按键、游戏默认或禁用。键盘输入发给当前前台窗口，Xbox 360 映射在 JR EAST（Xbox）模式生效。
Hidari 2 可在「软件设置 → N 比例模块」读取和保存 Odoriko 的牵引加速、滑行掉速和制动减速。两柄回 N 后再保存。模型模式从控制器点阵菜单选择。
连接后立即跟随实体当前位置；断线恢复也是如此。软件的“已就绪”表示控制器输出就绪，游戏识别需要下一步确认。

3. 需要时进行校准

成品已校准且显示准确时，可以跳过本步。若显示未校准或方向不符，点击“设备校准”。校准期间暂停游戏输入。

  1. 主手柄：点击“开始”，依次拨到 EB、B8～B1、N、P1～P5；每个卡位停稳后点击“采集卡位”，全部 15 点采集后点击“保存”。
  2. 换向器：点击“开始”，依次将开关拨到你希望的 F、N、R，分别采集并保存；N 必须是中间断开位置。
  3. 按钮：点击“开始”，按住希望用作 A 的实体按钮并采集；依次学习 B、X、Y 四个不同按钮，最后保存。
  4. 保存成功后关闭校准窗口，主窗口恢复连接。校准保存在控制器中，断电保留。未点击保存就关闭，会丢弃本次采集。

4. 选择游戏，再启动游戏

游戏主窗口选择注意
JR EAST Train Simulator（Steam）JR EAST（Xbox）先打开本程序。Steam 库中点击游戏的控制器图标，开启“使用 Steam 输入”，在当前布局中选择官方 Tsukasa Mascon 并点击“应用布局”，再进入游戏。
JR EAST Train Simulator（XInput 直连）JR EAST（Xbox）先打开本程序并确认硬件就绪，再从游戏自己的启动入口运行。支持原生 XInput 的版本可直接接收手柄输入。游戏的启动与授权要求由该版本决定。
RUNNING TRAINRUNNING TRAIN（ZUIKI）使用 Pro 换向器映射。Steam 库中右键游戏 → 属性 → 控制器 → 禁用 Steam 输入。
BVE 5/6BVE 5/6（专用插件）启用游戏中的JR Controller输入插件，见下方说明。
TRAIN CREWTRAIN CREW（官方接口）启用游戏的外部设备输入/输出；无需Steam Input。详细操作说明

切换游戏模式会释放旧输出，并切换虚拟设备或游戏接口。如果游戏已经启动但没有响应，请保持 JR Controller 运行并重启游戏。进入驾驶画面，确认游戏 HUD 跟随主手柄、换向器和按钮。按钮的具体用途由游戏决定。

JR 原生 XInput 直连：首次使用

  1. 安装本包中的 JR Controller，按提示完成驱动安装；如要求重启，重启后继续。
  2. 用 USB 连接配套控制器，打开 JR Controller，游戏模式选择 JR EAST（Xbox）。
  3. 拨动主手柄、换向器并按按钮，确认软件显示与硬件对应。已有有效校准且显示准确时，无需重新校准。
  4. 保持 JR Controller 运行，再用游戏要求的方式启动游戏。直连输入本身无需配置 Steam Input，游戏能否在退出 Steam 后启动尚未验证。
  5. 先进入单手柄车型，在停车状态检查 N、P1、B1、EB 和 F/N/R 是否对应游戏 HUD，再开始驾驶。
  6. 如果游戏已提前启动却没有反应，退出游戏，保持 JR Controller 运行，再启动游戏。若另有 Xbox 手柄，请先断开，避免游戏选择了其他手柄。
直连路径复用此前在中央线 E233 系 0 番台验证的 XInput 输出。其他游戏版本与车型请逐项核对。BVE5/6 使用专用插件，见下方说明。

BVE 5/6：首次使用

  1. 安装时可选择 BVE 5 与 BVE 6 的游戏目录（包含 BveTs.exe）。不安装游戏插件时留空；插件仍附带于程序安装目录的 BVE Plugins 文件夹。
  2. 主窗口选择 BVE 5/6（专用插件）。游戏右键 → Preferences → Input device → 勾选 JR Controller → OK。
  3. BVE 5 需要 BVE5 目录中的 32 位插件，BVE 6 需要 BVE6 中的 64 位插件。不要混用，退出游戏后再更新插件。
  4. A 鸣笛；B ATS 确认；X EB 确认；Y ATS 复位。车型档位数量不足时会缩放；京成 3500 的制动显示为角度。
连接或重连后实时跟随实体位置。BVE 模式下失联或暂停输出会撤销动力、释放按钮并紧急制动。主手柄与换向器的实机抽查通过，四按钮的线路效果尚未逐项人工验证。详细 BVE 说明

5. 软件设置

主界面的“接入说明”随游戏模式变化。进入“软件设置”可切换主题、查询 GitHub 发布版本、启用本机接口和配置 LED。

  • LED 点阵：选择档位后点击 8×8 网格绘制。亮度 0 到 15，旋转可选四个方向，点阵可关闭。点击“保存并应用”后，设置存在此电脑，设备连接时自动应用。旧固件需先更新。
  • 硬件与固件：连接设备后可检查并更新匹配的 hidari1 或 hidari2 固件。软件按设备上报的型号选包。先退出游戏，再确认型号与设备编号，按提示保持 USB 连接。校准留在设备内。
  • 本机 HTTP 接口：默认关闭。在“常规与更新”勾选启用并点击应用。默认读取地址 http://127.0.0.1:8765/v1/state。返回 JSON，connected 表示收到新鲜数据，valid 表示档位有效。notch 为 P1、N、B1、EB 等，reverser 为 F、N 或 R，buttons 的第 0 到 3 位对应 A/B/X/Y。请在 valid=true 时使用档位与按键。

遇到问题

现象下一步
一直等待插入控制器换一根数据线或 USB 接口，关闭串口调试工具；同时连接多个开发板时，只保留这台控制器。
驱动未就绪重启电脑。仍失败时，退出 JR Controller 后重新运行本安装包；安装器会尝试检查、修复已有驱动。
传感器异常或未校准未校准时按上面的步骤校准；传感器异常请联系硬件提供者检查磁铁和连接。
软件有变化，游戏没反应核对游戏模式。JR EAST Steam 版开启 Steam Input 并应用 Tsukasa Mascon 官方布局；原生 XInput 直连时保持软件运行后重新启动游戏；RUNNING TRAIN 禁用 Steam Input。保持软件开启后重启游戏。
更新提示旧程序正在运行从任务栏或桌面打开 JR Controller，点击“退出”，再回安装器重试。点击窗口右上角关闭也会退出程序。
安装失败在安装器点击“查看安装日志”，把日志交给提供安装包的人。日志位置：C:\ProgramData\JRController\setup.log。

以后使用

保持软件运行，插上硬件，选择对应游戏模式后启动游戏。无需重复安装或重新校准。卸载从 Windows“已安装的应用”进入；共用的 ViGEmBus 驱动会保留。
